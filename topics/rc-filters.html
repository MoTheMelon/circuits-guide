RC low-pass & high-pass filters

Because a capacitor's impedance changes with frequency, an R and a C make a frequency-dependent voltage divider. A low-pass passes slow signals and removes high-frequency noise (sensor smoothing, PWM-to-analog). A high-pass blocks DC and passes changes (AC coupling audio).

fc = 12πRC
Cutoff frequency: output is −3 dB (70.7%) here.
|HLP| = 1√(1 + (f/fc)²)
Low-pass gain. Falls 20 dB per decade above fc.
|HHP| = f/fc√(1 + (f/fc)²)
High-pass gain.
dB = 20 log10(Vout/Vin)
