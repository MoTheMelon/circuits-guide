Analog-to-digital conversion (ADC)

An ADC measures a voltage and returns an integer. Its resolution (bits) sets the step size, and its reference voltage sets full scale. Every analog sensor on this page ends here.

LSB = Vref2n
Smallest voltage step.
code = ⌊VinVref·2n⌋
Conversion. Back to volts: code × LSB.
Never exceed the reference.

Input pins are usually only safe from 0 V to the chip's supply. Scale higher voltages down with a divider, and add a 100 nF cap from the ADC pin to ground when the source impedance is high.
