Kirchhoff's laws (KVL & KCL)

Two bookkeeping rules let you solve any circuit. KCL (current law): the current flowing into a node equals the current flowing out, because charge doesn't pile up. KVL (voltage law): the voltages around any closed loop sum to zero, because energy is conserved.

Σ Iin = Σ Iout
KCL — at every node (junction dot).
Σ Vloop = 0
KVL — rises (sources) equal drops (loads) around a loop.
I1 = IT·R2R1+R2
Current divider (two branches): the smaller resistor takes more current.

Method for any circuit: label each node voltage, write KCL at each unknown node using I = (Va − Vb)/R for every branch, then solve the equations. This is called nodal analysis and is what SPICE does internally.
