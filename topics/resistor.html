Resistor & colour code

Resistors set currents, divide voltages, pull signals to a known level and limit LED current. Key specs: resistance, tolerance (±1% or ±5%), power rating, and package. Values come from standard "E-series" so each decade is evenly covered: E12 is 1.0, 1.2, 1.5, 1.8, 2.2, 2.7, 3.3, 3.9, 4.7, 5.6, 6.8, 8.2.

SMD codes.

3-digit: "472" = 47 × 10² = 4.7 kΩ. 4-digit: "4701" = 4.70 kΩ. "R" marks the decimal point: "4R7" = 4.7 Ω. EIA-96 codes ("01C") need a lookup table.
